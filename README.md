# Learn Rust

A personal study project to learn Rust programming language fundamentals and best practices.

## Purpose

This repository contains exercises, examples, and projects created while learning Rust, covering:

- Core language concepts
- Ownership and borrowing
- Error handling
- Collections and iterators
- Functions and modules
- Testing and documentation

## Getting Started

### Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) installed
- Cargo (comes with Rust)
